  • •Games and Canvas are rare in product UI

05 / 26
SPECS

Intent, not decoration

tween

Directed, timed · enter / morph

Use when: structure transitions, screen changes, sequential reveals.
Key: durationMillis, easing

spring

Physical · drag release, playful

Use when: gesture settle, interactive drag, playful taps.
Key: stiffness, dampingRatio

keyframes

Hand-authored · overshoot, pauses

Use when: cinematic story, race-then-settle, overshoot.
Key: at / using / durationMillis

infinite

Loop · ambient, loaders

Use when: spinners, pulsing indicators (sparingly).
⚠ Not for hero UI — it fights user attention.

SPECS · INTENT

GRAPHICS

Draw or place?

Custom drawing or layout?

├──Tint / shape / clip only?→ Modifier / Shape
├──Charts, gauges, game art?→ Canvas + DrawScope
├──Children in custom positions?→ custom Layout
├──Deferred / dependent measure?→ SubcomposeLayout

Canvas is not a layout system. Layout is not a drawing API.

WHY COMPOSE

Same behavior. Fewer moving parts.

BEHAVIOR XML / VIEW PARTS COMPOSE PARTS
Show / hide View.GONE↔VISIBLE + TransitionManager 3 AnimatedVisibility(visible) { } 1
Async button morph AnimatorSet + 4× ObjectAnimator + Listener 7 updateTransition — every property chained 1
Custom chart Custom View + onDraw() + ValueAnimator 4 Canvas { } + one Animatable 2
List → detail continuity MotionScene + 2+ ConstraintSets + Transition tag 4 SharedTransitionLayout + matching keys 2
Radial / fan picker Custom ViewGroup: constructors + onMeasure + onLayout 5 One Layout { measurables → placeRelative } block 1
Screen transitions 4 anim XML + 4 attrs on every graph <action> 4 transitionSpec on NavDisplay — once for the graph 2

Moving parts = distinct objects to create, wire, and keep in sync. Not line counts.

SHIP

Performance checklist

  1. 1graphicsLayer / draw / offset { } — not layout every frame
  2. 2Cache Path / paints in hot 60fps loops
  3. 3One shared clock for coordinated effects
  4. 4Don’t animate a state read in every parent
  5. 5Shared elements: stable keys, small regions
  6. 6Shaders / AGSL: API guards + fallbacks

Measure children, then placeRelative — that’s custom layout from scratch. Canvas is for pixels, not for placing children.

ANIMATION
